# tests/babylon/ — Babylon.js Visual Regression Driver

## Intent
Runs curated Babylon.js scenes against the software WebGL renderer in headless Chromium (Playwright), screenshots each scene, and compares against Babylon's own golden references (`ReferenceImages/*.png`) using Playwright-equivalent pixelmatch semantics. Entry: `npx tsx tests/babylon/run.ts` (= `npm run test:babylon`). Works end-to-end even with a stub renderer (no `renderer.js`): scenes fail with clear RENDERER_NOT_FOUND errors, driver completes, report written, exit code 1.

## Pipeline (per run)
1. `scenes.ts` parses `/testsuites/Babylon.js/packages/tools/tests/test/visualization/config.json` (**UTF-8 BOM!**) and selects runnable entries: 11 `sceneFolder+sceneFilename` ("file" kind) + 7 `scriptToRun+functionToCall` ("script" kind). The 835 `playgroundId` snippet entries are OUT OF SCOPE (skipped; see Design Decisions).
2. `server.ts` serves `empty.html` + the 5 vendor UMD bundles (`vendor/babylon-cdn/`: earcut.min.js, babylon.js, babylon.gui.min.js, babylonjs.materials.min.js, babylonjs.loaders.min.js), and proxies `/cdn/*` → `BABYLON_CDN` (default `https://cdn.babylonjs.com`) with an on-disk cache. Scene assets exist ONLY on the CDN — the foreign repo has no scene files.
3. `driver.ts`: per scene — new browser context (viewport 600×400, matching golden dims), `addInitScript(buildInterceptScript())` from `src/context-intercept.ts` (renderer injection; stub when `renderer.js` missing), `goto empty.html`, init engine (`preserveDrawingBuffer: true`, see Constraints), set `window.canvas` global, create scene, render `renderCount||1` frames + `scene.isReady()` poll, `page.screenshot()` (always taken, even on scene error → blank page for diffing). Captures page console error/warning lines and appends a summary to the failure reason (self-diagnosing reports).
4. `compare.ts`: pixelmatch (real lib, devDependency — same library Playwright uses) with `threshold` 0.035 and `maxDiffPixelRatio` = `errorRatio/100 || SCREENSHOT_MAX_PIXEL/100 || 1.1/100`, mirroring upstream `toHaveScreenshot` options.
5. `run.ts`: CLI orchestration, worker pool, JSON report → `tests/reports/babylon-report.json`, failed screenshots + diff PNGs → `tests/reports/babylon/`, exit non-zero on any failure.

## API Surface
CLI: `run.ts [--filter REGEX] [--full] [--workers N] [--renderer PATH] [--list] [--limit N] [--no-cache] [--timeout SECONDS] [--out PATH] [--cdn URL] [--root PATH]`
Env: `WEBGL_SOFTWARE_RENDERER` (renderer bundle; default `./renderer.js` — inherited from `src/context-intercept.ts`), `BABYLON_ROOT` (foreign repo; default `/testsuites/Babylon.js`), `BABYLON_CDN` (default `https://cdn.babylonjs.com`), `BABYLON_PORT` (default 0 = ephemeral), `SCREENSHOT_THRESHOLD` (default 0.035), `SCREENSHOT_MAX_PIXEL` (default 1.1; per-test `errorRatio` beats it).

Modules:
- `run.ts` — CLI parse, scene selection, server + browser lifecycle, worker pool, report, exit code
- `scenes.ts` — `SceneEntry` model, `loadConfig()`, curated lists, `selectScenes({full, filter, limit})`
- `driver.ts` — `runScene(browser, serverUrl, entry, opts)` → `SceneResult` (in-page engine/scene/render protocol; failure reasons enriched with page-console error summary)
- `compare.ts` — `sanitizeReferenceName()`, `goldenPath()`, `compareScreenshots()`
- `server.ts` — `createServer({cdn, cacheDir, noCache})` → `{port, url, close}`
- `empty.html` — page template (canvas `#babylon-canvas`, 100%×100%, loads vendor UMDs: earcut FIRST, then babylon core + extensions)

## Default scene list
Curated default (16): file — Sponza, Windows cafe, Espilit, The car (`errorRatio` 5), Viper, Retail, Hill Valley, Heart, SpaceDeK (`errorRatio` 5), Flat2009; script — Fog, Polygon, Lines, Lens, Self shadowing, GUI (`errorRatio` 4). `--full` adds Mansion and Procedural textures (both `excludeFromAutomaticTesting: true` upstream). ## Constraints
- `/testsuites/Babylon.js` is READ-ONLY — goldens + config.json are read at runtime, never modified.
- Scene assets are CDN-only → served through the `/cdn` proxy; `--no-cache` disables the disk cache; on network outage each scene fails with a clear error and the driver still completes and reports.
- No playground snippets (835 entries) — out of scope by design decision.
- Deviations from upstream harness (documented, intentional): (1) engine created WITHOUT `failIfMajorPerformanceCaveat` (a software renderer would trip it); (2) no draco/ktx2/basis/gltf-validation decoder configs (not served) — scenes relying on them show asset/decoder errors, recorded per scene; (3) `useHighPrecisionFloats: true`, `forceSRGBBufferSupportState: true`, `powerPreference: "high-performance"`, `disableWebGL2Support: false` kept as upstream; (4) `preserveDrawingBuffer: true` in the engine options — REQUIRED: the software renderer's CTS-compliant rAF preserve-clear (`src/gl/draw.ts schedulePreserveClear`) wipes the drawing buffer and re-presents BLACK after the render loop stops; without it every screenshot is pure black (upstream doesn't set it — native GPU keeps compositing the last frame); (5) `window.canvas` is set (`document.getElementById("babylon-canvas")`) before engine creation, mirroring upstream `visualizationPlaywright.utils.ts:367` — cached scene scripts (shadows.js, gui.js) reference the bare global `canvas`; (6) `earcut.min.js` is loaded before babylon.js in `empty.html`, mirroring upstream script order — Babylon core uses the global `earcut` as default triangulator.
- Determinism recipe (must match upstream): seed `window.seed = 1` + sine-LCG `Math.random` BEFORE scene creation; `scene.useConstantAnimationDeltaTime = true`; `engine.getCaps().parallelShaderCompile = undefined`; `engine.enableOfflineSupport = false`; `engine.setDitheringState(false)`; `BABYLON.SceneLoader.ShowLoadingScreen = false`; `ForceFullSceneLoadingForIncremental = true`; disable `activeCamera.useAutoRotationBehavior`; viewport 600×400.
- Cache + report dirs live under `tests/reports/` (gitignored at repo root).
- Files ≤ ~1000 lines; zero runtime deps beyond devDeps (playwright, sharp, pixelmatch, tsx).

## Design Decisions
- **Vendored pixelmatch** (`pixelmatch.cjs` + `pixelmatch.d.ts`): byte-for-byte copy of playwright-core 1.59.1's `lib/third_party/pixelmatch.js` (mapbox/pixelmatch, ISC — Playwright's own copy, so diff counts match `toHaveScreenshot` semantics by construction). The npm `pixelmatch` devDependency is declared in package.json but NOT actually installed in this environment, so the spec's fallback rule (vendor playwright's copy with attribution) applies. The file is `.cjs` because the repo's `"type": "module"` would mis-parse the CJS `module.exports` file as ESM under tsx (vitest tolerates it via its transform pipeline; tsx does not); `compare.ts` loads it via `createRequire(import.meta.url)` typed by `pixelmatch.d.ts`. `compare.test.ts` has a parity test asserting identical diff counts between our copy and playwright-core's live copy on synthetic opaque images (identical / single-pixel diff / gradient / checkerboard, threshold 0.035; skips if playwright-core is absent). Invocation mirrors `playwright-core/lib/server/utils/comparators.js`: `pixelmatch(a, b, diff, w, h, { threshold })` — threshold is the ONLY option. `compareScreenshots` decodes both PNGs with sharp (`removeAlpha().ensureAlpha()` → RGBA opaque — note: `removeAlpha()` alone yields 3-channel RGB, which pixelmatch rejects), runs pixelmatch into a diff buffer, `pass = diffPixels <= maxDiffPixelRatio * w * h`; size mismatch or missing golden → explicit failure reason.
- **Golden naming**: `(referenceImage || title).replace(".png","") + ".png"`, then Playwright filepath sanitization (runs of chars outside `[A-Za-z0-9._-]` → `-`). Known upstream mismatch: 10 config `referenceImage` values use underscores while disk files use dashes (`ext_lights_ies`→`ext-lights-ies`, `pbr_mirror`, `nme_glow_*`, `openpbr_base_*`) — avoid in curated list; if selected they fail golden lookup and are reported as missing.
- **`/cdn` proxy** keeps the page same-origin (no CORS edge cases for `.babylon`/texture loads) and the on-disk cache makes repeat runs offline-capable. `rootPath` does NOT change the fetch URL (upstream semantics); it only prefixes `replaceUrl` rewrites.
- **earcut vendoring**: earcut is NOT on cdn.babylonjs.com — `vendor/babylon-cdn/earcut.min.js` + `earcut.license` are a byte-identical copy of `/testsuites/Babylon.js/packages/tools/babylonServer/public/earcut.min.js` (+ `.license`). `scripts/fetch-babylon-cdn.sh` vendors earcut from the local repo checkout (npm CDN fallback: unpkg earcut@2.2.4 + mapbox/earcut LICENSE) and resolves the Babylon version from the local repo.
- **scriptToRun semantics (ported verbatim from upstream `visualizationPlaywright.utils.ts`)**: fetch `root + scriptToRun`; asset rewrites `../../assets/`, `../../Assets/`, `/assets/` → `root + "/Assets/"`; `replace` = comma-split `[from,to]` pairs, literal first-occurrence `String.replace`; `replaceUrl` = comma-split regex sources, each globally replaced with `root + rootPath + source`; then `window.scene = eval(script + "\n" + functionToCall + "(engine)")`. `specificRoot` → `BABYLON.Tools.BaseUrl = root + specificRoot`.
- **Snippet support (835 tests) is future work** — recipe: fetch `https://snippet.babylonjs.com/{id}` JSON, `typescript.transpileModule` TS→JS, strip module syntax, scene-call detection order `Playground.CreateScene` → `delayCreateScene` → `delayLoadScene` → `CreateScene` → `createScene`, rewrite `textures/` → `https://playground.babylonjs.com/textures/`, apply per-test `replace` pairs.

## Test Strategy
- Smoke (plumbing proof): `npx tsx tests/babylon/run.ts --limit 3 --workers 2` with no `renderer.js` → 3 failures with RENDERER_NOT_FOUND, driver completes, report + screenshots written, exit 1.
- Unit: `npx vitest run tests/babylon` — `scenes.test.ts` (BOM parsing, kind detection, curated/full/filter selection, missing-golden skip), `compare.test.ts` (identical→pass, diff-within-ratio→pass, beyond-ratio→fail, threshold semantics, sanitization).
- Real renderer: run against built `renderer.js`, iterate the RENDERER until scenes converge toward goldens (diffs > 0.035 threshold or > ratio still reported per scene). Current status (HEAD ce8a79c, full 16-scene run): **9/16 PASS** — Espilit, Viper, Retail, SpaceDeK, Fog, Polygon, Lines, Self shadowing, GUI. All 7 residual failures are visual diffs (ok:true, ready:true, no console errors, no timeouts) — see Known Issues for the per-scene ratio list.

## Known Issues (current state — harness black-screen fixes are IN: driver preserveDrawingBuffer + window.canvas, earcut vendored+loaded; renderer standard-material compile blocker FIXED at ce8a79c, default-VAO alias FIXED at 5bd0c89)
- **Residual visual-diff failures (renderer-side raster fidelity, NOT harness — 7/16 fail at HEAD ce8a79c; all ok:true, ready:true, no console errors, no timeouts)**: Sponza 0.0766, Windows cafe 0.0139, The car 0.0831, Hill Valley 0.0861, Heart 0.0205, Flat2009 0.0246 (maxDiff 0.011; The car maxDiff 0.05), Lens 0.3486. Per-pixel classification of Sponza/The car/Hill Valley (temp-bundle run at HEAD; ratios reproduced exactly) — see "Diff classification" below. Windows cafe / Heart / Flat2009 are near-pass (≤2.5% diff, <0.5% px |Δluma|>50) — AA/edge/precision level. Lens 0.349: golden has 7.9% pixels with luma>200 vs 0.7% in render (~17k bright flare/glow pixels missing → additive-blended sprite/glow path suspect).
- **Scene texture setup facts (from the CDN-cached .babylon files — parse `tests/reports/babylon-cache/<sha1(url)>.bin`; sha1 of the `https://cdn.babylonjs.com` URL, MIME in `.meta`)**: Sponza (3 omni lights), The car (2 omni), Hill Valley (1 omni) all have **ZERO shadow generators** — lighting is baked (VRayLightingMap-style ambient/lightmap textures, e.g. `Sponza-FloorVRayLightingMap.jpg`, `route_LM .jpg`); NO compressed textures (no ktx/dds); ALL ~400 texture refs in the 3 scenes lack `samplingMode`/`anisotropicExtension` → Babylon defaults apply: TRILINEAR + `anisotropicFilteringLevel=4` (verified in `vendor/babylon-cdn/babylon.js`: `samplingMode?t.TEXTURE_TRILINEAR_SAMPLINGMODE:i.samplingMode`, constructor default `anisotropicFilteringLevel=4`). Hill Valley materials are pure emissive `[1,1,1]` (texture = final color, no lighting math). The car chrome uses cube reflection `reftest` (isCube, CUBIC_MODE, level 0.8/0.1). Sky texture `Ciel15.jpg` is **NPOT 1024x256** (most others POT 256-2048). Vignette `degradecine.png` 64x64 with alpha (corners render clean — vignette path OK).
- **Diff classification (Sponza / The car / Hill Valley, HEAD temp bundle)**: global luma matches (Δ +0.4/+0.6/+1.0); NO positional offsets anywhere (2D shift-search best-fit = (0,0) in all hot regions → not UV/projection shifts). **Sponza**: diffs concentrate bottom-center (floor; 8x8 mean|dY| grid peaks 14.8 at row6-col3), render BLURRIER there (gradient-energy ratio rendered/golden 0.62-0.86 vs 1.0-1.14 top half). **The car**: one contiguous top-center block (sky band y<110, x≈150-450, |dY| 35-50); render slightly smoother there (0.87-0.89), bottom third sharper (1.05-1.34); 79% of >20-diff px sit on strong golden edges; the 1.51% >50-luma-diff px are ALL in the sky band (bbox y[2-138]), NOT on the car body; 31.5% of them in golden-luma >180 (sun/sky), rendered brighter/darker ~50/50. **Hill Valley**: compact blob upper-left (y≈120-180, x≈0-112, |dY| 20-50 — clock tower / bright facade area) rendered +11.5 luma brighter (neutral ΔR≈ΔG≈ΔB — emissive material, so pure texture-sampling difference) and slightly smoother there (0.93-0.98); bottom third (ground/grass) strongly SHARPER/aliased (gradient ratio 1.23-1.85); >50 px only 0.06%, mostly dark-region pixels rendered brighter. **Verdict**: NOT shadow-map precision (no dynamic shadows), NOT compressed-texture decode (none loaded). Pattern is per-region/per-texture mixed (some regions blurrier, others aliased) → suspect mip-chain generation (incl. NPOT 1024x256 sky) and/or anisotropy fidelity on grazing-angle surfaces (floor, sky). Aniso GL state verified WORKING at runtime: `getExtension('EXT_texture_filter_anisotropic')` non-null, `MAX_TEXTURE_MAX_ANISOTROPY_EXT`=16, `texParameterf(0x84fe, 4)` stored and readable via getTexParameter. Parent candidates to route: `src/gl` generateMipmap (mip level dims/filters, sRGB), `src/raster/sampler.ts` λ/aniso math (lines 268-351), lightmap UV2 sampling (`coordinatesIndex: 1`).
- **`WEBGL_SOFTWARE_RENDERER` env poisoning** (inherited from `src/context-intercept.ts`): if the env var points to a NONEXISTENT file, `buildInterceptScript()` silently returns the RENDERER_NOT_FOUND stub → every scene fails with RENDERER_NOT_FOUND errors. ALWAYS pass `--renderer ./renderer.js` (or a real path) explicitly.
