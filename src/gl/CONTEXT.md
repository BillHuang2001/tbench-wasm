# src/gl/ — WebGL API Surface (WebGL1 + WebGL2 contexts)

## Intent
The complete WebGL 1.0 (`WebGLRenderingContext`) and WebGL 2.0 (`WebGL2RenderingContext`) API surface of the software renderer: all GL state, all WebGL object classes, the error queue, per-call validation, attribute fetch + vertex evaluation, draw-call assembly into the rasterizer, texture/FBO management, readPixels/clear/blit, context lifecycle, and the extension registry. Pure TS, zero runtime deps. Consumes `glsl/` (shader compile/link — contract §1 in `../CONTEXT.md`), `raster/` (DrawCall, formats, sampler, surfaces — contracts §2/§3), `present/` (canvas surfaces, image decode — contract §4). Those modules' `index.ts` files carry the full types; gl/ compiles against them.

**Phase status: Phase 1 (architecture) complete.** All files exist as typed stubs (methods throw `Error('GL stub')`). Phase 2 implements: `api/` mixin modules (validation + delegate to engine), engine modules (`draw.ts`, `teximage.ts`, `getters.ts`, `lifecycle.ts`), and extension factories.

## API Surface
- `index.ts` — barrel: exports both context classes, constants (`C1`, `C2`, `CExt`, `C`), all object classes, state model, errors, validation, engine entry points, extension registry + types, `installAll`.
- `webgl1.ts` — `class WebGLRenderingContext` with EVERY WebGL1 method declared (exact spec signatures; arity matters — CTS checks `function.length`). `canvas`/`drawingBufferWidth`/`drawingBufferHeight` are prototype getters. `CONTEXT_TOKEN: unique symbol` gates construction (only `lifecycle.ts` may construct). Bottom: `installConstants(WebGLRenderingContext.prototype, C1)`.
- `webgl2.ts` — `class WebGL2RenderingContext extends WebGLRenderingContext` (prototype chain ⇒ `instanceof WebGLRenderingContext` true) with all WebGL2 additions (queries, TF, samplers, VAOs, sync, UBOs, instanced/ranged draws, integer textures, texImage3D/texStorage*, multisample, drawBuffers/readBuffer, clearBuffer*, ...). Bottom: `installConstants(WebGL2RenderingContext.prototype, C2)`.
- `constants.ts` — `C1` (all WebGL1 GLenum values), `C2` (WebGL2 values), `CExt` (extension constants incl. compressed formats, timer query, norm16, clip/cull, draw-buffers), merged `C` for engine use, `installConstants(proto, table)` (enumerable, non-writable properties — spec requires constants on the prototype).
- `state.ts` — `State` interface + `createDefaultState(version: 1|2)` with spec defaults; `Limits`/`defaultLimits()`; `VertexAttribState` (constantF default [0,0,0,1]), `VAOState`, `BlendState`, `StencilState`, `PixelStoreUnpack/Pack`, `TextureUnitState`. Plain mutable data, no logic.
- `errors.ts` — `ErrorQueue` (push/get/peek/hasErrors/clear; cap 256, spec ordering).
- `validation.ts` — `validateObject` (TypeError for non-WebGLObject; INVALID_OPERATION + null for cross-context/deleted; null is legal for nullable params), numeric/enum/string guards.
- `objects/` — one file per class: WebGLObject (abstract base: private `_context` tag, `_deleted`), WebGLBuffer (`_target`, `_data`, `_size`, `_usage`, `_deletePending`, `_tfRangeBindings`), WebGLTexture (`_levels[faceIndex][level]`, `_params` — spec defaults incl. MIN_FILTER=NEAREST_MIPMAP_LINEAR, MAX_LEVEL=1000, MIN/MAX_LOD=∓1000, MAX_ANISO=1), WebGLShader (+`ShaderCompileResult`), WebGLProgram (+`ProgramModel`: attributes/uniforms/uniformBlocks/varyings/vertex.run/fragment.run/usesPointSize/usesGLPointCoord/usesFragData; `_uniformStore: DataView|null`, `_blockStores`, `_bindAttribLocations`, `_transformFeedbackVaryings`, `_tfBufferMode`, `_linkComplete`), WebGLFramebuffer (`_attachments: Map<GLenum, FramebufferAttachment>`, `_status`, `_multisampled`), WebGLRenderbuffer, WebGLVertexArrayObject (holds VAOState), WebGLSampler, WebGLQuery (`_active`, `_result`, `_resultAvailable`), WebGLSync (immediate-signaled), WebGLTransformFeedback, `aux.ts` (WebGLUniformLocation {_program,_index,_name}, WebGLActiveInfo, WebGLShaderPrecisionFormat), `index.ts` (barrel + `OBJECT_CLASSES` + `Resources` track/untrack/invalidateAll + `createObject`).
- `extensions/` — `index.ts`: `EXTENSION_SPECS` registry (canonical name, aliases, `versions: 1|2[]`, status), `getSupportedExtensionNames(version)`, `getExtensionObject(ctx, name)` (alias-aware, version-checked, singleton cache on `ctx._extensions`); `types.ts`: full interfaces for every extension. **Factories currently throw** (`createExtension` → "not implemented yet") — Phase 2 must land them before tests run. `getSupportedExtensions()` lists IFF `getExtension()` returns an object (hard CTS invariant — get-extension.html).
- Engine modules (deep logic, called by api/ after validation): `draw.ts` (`executeDraw`/`executeClear`/`executeReadPixels`/`executeBlitFramebuffer`/`executeClearBuffer` + `DrawRequest` — the contract §2 pipeline: attr fetch → per-vertex `vertex.run` → packed records → TF capture → occlusion hook → `rasterizer.draw`), `teximage.ts` (upload/copy/compressed/mipmap/storage with full overload dispatch + pixelStore semantics), `getters.ts` (getParameter table), `lifecycle.ts` (`createContext` WeakMap registry: one context per canvas per type-slot; 'webgl'+'experimental-webgl' share slot; webgl2 conflicts → null; resize/lose/restore).
- `api/` — prototype-mixin modules, one per method group: `context.ts`, `state.ts`, `buffers.ts`, `vertex-attrib.ts`, `textures.ts`, `teximage.ts`, `programs.ts`, `uniforms.ts`, `framebuffers.ts`, `draw.ts`, `webgl2.ts`; each exports `installXxx(proto)` (assignment preserves arity). `index.ts` `installAll(proto)` aggregates. **Wiring point: call `installAll(WebGLRenderingContext.prototype)` at module-load bottom of `webgl1.ts`** (currently unwired — stubs still throw; safe to wire anytime).

## Constraints
- Each file ≤ ~1000 lines (mixin pattern exists precisely for this; do NOT grow webgl1.ts/webgl2.ts class bodies beyond signatures — implementations live in api/ modules).
- Zero runtime deps; no DOM in core paths (canvas is abstract via present/).
- GL error semantics: WebIDL conversion failures THROW TypeError (JS conversion per WebGL spec); cross-context/deleted objects → INVALID_OPERATION + no-op; internal exceptions NEVER escape — catch at the API boundary, report via GL errors. Error queue ordering per spec (oldest first, FIFO).
- No per-fragment allocation in hot paths (draw pipeline uses preallocated typed-array scratch; see `../raster/` contract §2).
- Correct method arity (function.length) and prototype placement: constants + getters on prototype, non-writable.
- All validation must match the WebGL spec: value ranges, buffer offsets/alignment (UNPACK_ALIGNMENT, uniform buffer offset alignment 256), FBO completeness before draw (INVALID_FRAMEBUFFER_OPERATION), program link state, uniform type/size mismatch → INVALID_OPERATION (no silent corruption), MAX_* limits consistent with `Limits`/`defaultLimits()`.
- Contract §1 conformance: `compileShader`/`linkProgram` from glsl/; ProgramModel.uniforms[].location is the index into the per-program `_uniformStore` DataView (uniform* calls write there); sampler values validated < MAX_COMBINED_TEXTURE_IMAGE_UNITS; matrix transpose must be false (INVALID_VALUE).
- Contract §2 conformance: vertex records packed `[px,py,pz,pw, pointSize, varyings...]` per Program.varyings; DrawCall carries the full state snapshot (see `draw.ts`).
- Contract §5 conformance: state.ts defaults match the WebGL initial-state table (dither default true, stencil ops KEEP, etc.); objects validate via `_context` tag.

## Design Decisions
- **Class hierarchy**: `WebGL2RenderingContext extends WebGLRenderingContext` (prototype chain ⇒ instanceof works both ways); WebGL1 class carries all base methods; WebGL2 adds on top. Interface merging adds typed getExtension overloads per implemented extension.
- **Prototype-mixin implementation**: class declarations own signatures + arity; `api/<group>.ts` replaces stub bodies via assignment. Single home per concern; files stay small.
- **Constants**: one table per version + extension table, installed enumerable/non-writable on prototypes (spec). Extension constants live ONLY on extension objects. Values verified against `/testsuites/WebGL/specs/latest/2.0/index.html` + extension XMLs (see git history of `constants.ts` for provenance).
- **Error/validation model**: TypeError for WebIDL conversion failures; INVALID_* via ErrorQueue; internal exceptions swallowed at API boundary. `validateObject` rejects cross-context AND fake objects (CTS type-conversion).
- **State layout**: `State` in state.ts is plain data; per-attrib state lives in VAOState (attribs + ELEMENT_ARRAY_BUFFER); ARRAY_BUFFER binding + everything else is context state. WebGL2 state (UBO bindings, pack/unpack buffers, TF, drawBuffers, samplers) exists from construction (`createDefaultState(2)`).
- **Uniform store**: per-program DataView laid out by glsl/ ProgramModel; uniforms with blockIndex ≥ 0 live in block stores; getUniformLocation → WebGLUniformLocation {_program, _index, _name}; validateUniformLocation checks program match + link state.
- **Limits** (generous software values, in `defaultLimits()`): MAX_TEXTURE_IMAGE_UNITS=16, MAX_COMBINED=32, MAX_DRAW_BUFFERS=8, MAX_COLOR_ATTACHMENTS=8, MAX_SAMPLES=4 (software MSAA resolve on blitFramebuffer so CTS `multisampled_depth_*`/`multisample-with-full-sample-counts` pass), UNIFORM_BUFFER_OFFSET_ALIGNMENT=256, MAX_CLIENT_WAIT_TIMEOUT_WEBGL=0, MAX_TEXTURE_SIZE=8192, MAX_CUBE=8192, MAX_3D=2048, MAX_ARRAY_TEXTURE_LAYERS=2048, MAX_VERTEX_ATTRIBS=16, MAX_VARYING_VECTORS=64, ALIASED_POINT_SIZE_RANGE=[1,1024], ALIASED_LINE_WIDTH_RANGE=[1,1], MAX_TEXTURE_MAX_ANISOTROPY_EXT=16.
- **Occlusion queries count real samples** via a rasterizer feedback hook on DrawCall (coordinate with `../raster/` in Phase 2). Sync objects signaled immediately (synchronous renderer). TF draws bypass the rasterizer, count primitives, validate primitive mode; queries not counted during TF.
- **Extension status** (registry is the source of truth): 'implement' — ANGLE_instanced_arrays, EXT_blend_minmax, EXT_frag_depth, EXT_shader_texture_lod, EXT_sRGB, OES_element_index_uint, OES_fbo_render_mipmap, OES_standard_derivatives, OES_texture_float(+_linear), OES_texture_half_float(+_linear), OES_vertex_array_object, WEBGL_depth_texture, WEBGL_draw_buffers, WEBGL_blend_func_extended, WEBGL_lose_context, WEBGL_debug_renderer_info, WEBGL_debug_shaders, EXT_texture_filter_anisotropic (aliases WEBKIT_/MOZ_), EXT_clip_control, EXT_color_buffer_float, EXT_color_buffer_half_float, EXT_float_blend, EXT_texture_norm16, KHR_parallel_shader_compile, OES_draw_buffers_indexed, WEBGL_clip_cull_distance, WEBGL_multi_draw, WEBGL_multisampled_render_to_texture, WEBGL_render_shared_exponent. 'null' (getExtension → null; every graded CTS extension test passes "No X support -- this is legal"): all compressed formats (s3tc, s3tc_srgb, astc, etc, etc1, pvrtc, bptc, rgtc), EXT_disjoint_timer_query(+webgl2), EXT_depth_clamp, EXT_polygon_offset_clamp, WEBGL_polygon_mode, EXT_texture_mirror_clamp_to_edge, OVR_multiview2, and other optional ones in `EXTENSION_SPECS`. Core-promoted WebGL1 extensions are NOT exposed on WebGL2 (versions:[1]); EXT_disjoint_timer_query must NOT be advertised on WebGL2 (CTS checks).
- **Drawing-buffer lifecycle**: WeakMap canvas registry; one context per (canvas, type-slot); conflicting getContext → null. Canvas width/height changes resize drawing buffer + reset state per spec (verify against CTS `canvas/` tests in Phase 2). `preserveDrawingBuffer:false` is a hint — buffer persists so screenshots see the last frame. antialias reported as requested but buffer is single-sampled (honest value; verify vs CTS `context/context-attributes.html` in Phase 2).

## Known Issues
- `getExtensionObject` throws for 'implement' specs until Phase 2 factories land — tests must not run before then.
- `api/index.ts installAll` is NOT yet invoked from webgl1.ts (stubs throw until wired — intentional Phase 1 state; wire at Phase 2 start).
- deqp suite (optional, `tests/deqp/`) counts millions of reportResults calls in-process — never route results through the DOM (root CONTEXT.md).
- WebGL1 NPOT restrictions, cube-map completeness, and `generateMipmap` base-format rules are exacting — implement against CTS `textures/` and `misc/` tests (Phase 2), not by approximation.
