# src/gl/ — WebGL API Surface (WebGL1 + WebGL2 contexts)

## Intent
The complete WebGL 1.0 (`WebGLRenderingContext`) and WebGL 2.0 (`WebGL2RenderingContext`) API surface of the software renderer: all GL state, all WebGL object classes, the error queue, per-call validation, attribute fetch + vertex evaluation, draw-call assembly into the rasterizer, texture/FBO management, readPixels/clear/blit, context lifecycle, and the extension registry. Pure TS, zero runtime deps. Consumes `glsl/` (shader compile/link — contract §1 in `../CONTEXT.md`), `raster/` (DrawCall, formats, sampler, surfaces — contracts §2/§3), `present/` (canvas surfaces, image decode — contract §4). Those modules' `index.ts` files carry the full types; gl/ compiles against them.

**Phase status: Phase 2 COMPLETE + wave-5 conformance2 API-core COMPLETE.** All `api/` mixins, engine modules, object classes, and extension factories are implemented and wired. `installAll` is invoked at the bottoms of `webgl1.ts`/`webgl2.ts`. `npx tsc --noEmit` clean; unit tests 115/115.

## API Surface
- `index.ts` — barrel: exports both context classes, constants (`C1`, `C2`, `CExt`, `C`), all object classes, state model, errors, validation, engine entry points, extension registry + types, `installAll`.
- `webgl1.ts` — `class WebGLRenderingContext` with EVERY WebGL1 method declared (exact spec signatures; arity matters — CTS checks `function.length`). `canvas`/`drawingBufferWidth`/`drawingBufferHeight` are prototype getters. `CONTEXT_TOKEN: unique symbol` gates construction (only `lifecycle.ts` may construct). Bottom: `installConstants(proto, C1)` + `installAll(proto)` + `chainToNative(proto, 'WebGLRenderingContext')` + `makePrototypeMethodsNonEnumerable` (offscreencanvas/methods-2: WebIDL methods must not be enumerable).
- `webgl2.ts` — `class WebGL2RenderingContext extends WebGLRenderingContext` (constructor `super()` + typing; in NODE the prototype chain also makes `instanceof WebGLRenderingContext` true) with all WebGL2 additions incl. `copyBufferSubData`, `drawingBufferStorage`, `releaseShaderCompiler`. Bottom: `installConstants(proto, C1)` + `installConstants(proto, C2)` (full constant surface as OWN props — required once the prototype is re-chained), `installAll(proto)` (idempotent; entry.ts also calls), copies the 3 class-body getters from the WebGL1 prototype, then `chainToNative(proto, 'WebGL2RenderingContext')` (REPLACES the class-extends prototype link with the native WebGL2 link in browsers) + `makePrototypeMethodsNonEnumerable`.
- `native-chain.ts` — `chainToNative(ourProto, nativeGlobalName)`: re-chains a class prototype under the native browser class of the same name (browser only; guarded no-op in Node). PROTOTYPE-ONLY — never touches constructor `[[Prototype]]` (that would redirect `super()` to the illegal native constructor). See "Native instanceof chaining" design note below.
- `constants.ts` — `C1` (WebGL1 GLenum values), `C2` (WebGL2 values), `CExt` (extension constants incl. compressed formats, timer query, norm16, clip/cull, draw-buffers), merged `C` for engine use, `installConstants(proto, table)` (enumerable, non-writable). NOTE: C1/C2 are exactly the constants installed on the context prototypes — CTS `constants-and-properties*.html` enumerate `for (var i in gl)` and fail on ANY extra non-function property. Values removed from the WebGL spec or added post-CTS-suite live in `CInternal` (merged into `C`, never installed). NOTE: constants.ts follows the Khronos **WebGL** convention where NEAREST_MIPMAP_LINEAR=0x2702 / LINEAR_MIPMAP_NEAREST=0x2701 (swapped vs OpenGL ES) — the raster sampler MUST interpret raw filter values per this same convention.
- `state.ts` — `State` interface + `createDefaultState(version: 1|2)` (+ alias `createState`) with spec defaults; `Limits`/`defaultLimits()`; per-attrib/VAO/Blend/Stencil/PixelStore state. Plain mutable data, no logic.
- `errors.ts` — `ErrorQueue` (push/get/peek/hasErrors/clear; cap 256, spec ordering).
- `validation.ts` — `validateObject` (TypeError for non-WebGLObject; INVALID_OPERATION + null for cross-context/deleted), numeric/enum/string guards.
- `objects/` — one file per class: WebGLObject (abstract base: `_context` tag, `_deleted`), WebGLBuffer (`_target`, `_data`, `_size`, `_usage`, `_deletePending`, `_tfRangeBindings`), WebGLTexture (`_levels[faceIndex][level]`, `_params` — spec defaults incl. ## Constraints
- Each file ≤ ~1000 lines (mixin pattern exists precisely for this; do NOT grow webgl1.ts/webgl2.ts class bodies beyond signatures — implementations live in api/ modules).
- Zero runtime deps; no DOM in core paths (canvas is abstract via present/).
- GL error semantics: WebIDL conversion failures THROW TypeError (JS conversion per WebGL spec); cross-context/deleted objects → INVALID_OPERATION + no-op; internal exceptions NEVER escape — catch at the API boundary, report via GL errors. Error queue ordering per spec (oldest first, FIFO). WebIDL NaN/Infinity → 0 via `Number(v) >>> 0` (blitframebuffer-test typo `gl.COLOR_ATTACHENT0` must not pageerror).
- No per-fragment allocation in hot paths (draw pipeline uses preallocated typed-array scratch).
- Correct method arity (function.length) and prototype placement: constants + getters on prototype, non-writable.
- All validation must match the WebGL spec: value ranges, buffer offsets/alignment (UNPACK_ALIGNMENT, uniform buffer offset alignment 256), FBO completeness before draw (INVALID_FRAMEBUFFER_OPERATION), program link state, uniform type/size mismatch → INVALID_OPERATION, MAX_* limits consistent with `Limits`/`defaultLimits()`.
- Contract §1 conformance: `compileShader`/`linkProgram` from glsl/; ProgramModel.uniforms[].location is the index into the per-program `_uniformStore` DataView (uniform* calls write there); sampler values validated < MAX_COMBINED_TEXTURE_IMAGE_UNITS; matrix transpose must be false (INVALID_VALUE).
- Contract §2 conformance: vertex records packed `[px,py,pz,pw, pointSize, varyings...]` per Program.varyings (`RECORD_HEADER_FLOATS = 5`); DrawCall carries the full state snapshot.
- bindBufferRange/bindBufferBase: offset+size>buffer-size is NOT an error at BIND (deferred to draw, ANGLE issue 3388); the 65536 MAX_UNIFORM_BLOCK_SIZE check applies to the range SIZE not the offset; WebGL2 allows multi-target buffer rebinds.

## Design Decisions (CTS-backed where noted)
- **Class hierarchy**: `WebGL2RenderingContext extends WebGLRenderingContext` (constructor `super()` + typing; in NODE the prototype chain also makes `instanceof WebGLRenderingContext` true for WebGL2 contexts). In BROWSERS the prototypes are re-chained under the native classes (see "Native instanceof chaining"); WebGL1 class carries all base methods; WebGL2 adds on top. Interface merging adds typed getExtension overloads.
- **Native instanceof chaining**: the CTS harness checks `ctx instanceof WebGLRenderingContext`/`WebGL2RenderingContext` (and object identity via instanceof) against the NATIVE browser classes (`webgl-test-utils.js` `isWebGLContext`) — a failed check falls back to `gl.getImageData(...)` and breaks rendering tests. `native-chain.ts` `chainToNative` re-chains each of our class prototypes UNDER the native prototype of the same name (browser only; guarded no-op in Node). Mapping: the 2 context classes + all 14 concrete object classes (objects/index.ts bottom). The abstract `WebGLObject` base is NOT chained (only instance fields, no runtime instanceof checks against it). PROTOTYPE-ONLY: constructor `[[Prototype]]`s are untouched (native WebGL constructors are illegal — redirecting `super()` would throw "Illegal constructor"). Consequences in browsers: (a) WebGL2 instances are NO LONGER `instanceof WebGLRenderingContext` — mirrors native Chromium (separate interfaces); (b) instances keep `instanceof OurConcreteClass`, so all internal instanceof checks stay valid; (c) the WebGL2 prototype must own everything it previously inherited through the class-extends chain — hence C1 constants and the `canvas`/`drawingBufferWidth`/`drawingBufferHeight` getters are installed as OWN properties on `WebGL2RenderingContext.prototype` in webgl2.ts.
- **Prototype-mixin implementation**: class declarations own signatures + arity; `api/<group>.ts` replaces stub bodies via assignment.
- **Error/validation model**: TypeError for WebIDL conversion failures; INVALID_* via ErrorQueue; internal exceptions swallowed at API boundary.
- **antialias reporting**: W1 reports `false` (CTS requires real AA pixels for true); W2 reports exactly what was requested. Buffer is single-sampled in both cases.
- **failIfMajorPerformanceCaveat**: always create the context and report the requested value — no CTS test exercises it; software implementations may return null per spec but creating is safer.
- **Resize semantics** (verified against CTS): realloc + clear (color 0, depth 1.0, stencil 0), viewport/scissor/state preserved, zero-size → 1×1, `drawingBufferWidth/Height` live getters.
- **Context loss** (CTS context-lost PASSES): events dispatched async; `preventDefault()` on the lost event gates restore; resize while lost reallocates nothing but stays lost. While lost: getters return null; ALL void calls are SILENT no-ops; `loseContext()` on an already-lost context → INVALID_OPERATION and `restoreContext()` on a live context → INVALID_OPERATION; create* return NON-NULL objects with NO error; is* on such objects returns false. `getError()` while lost: FIRST call per loss epoch returns CONTEXT_LOST_WEBGL, subsequent calls drain normally. The extension singleton cache is untouched by the lost path; `doRestore` re-creates non-WEBGL_lose_context singletons while WEBGL_lose_context keeps identity.
- **RGB8 color attachment on WebGL2** → COMPLETE for BOTH texture and renderbuffer attachments (GLES3 Table 3.13; rgb-format-support.html + framebuffer-render-to-layer.html hard-require COMPLETE for RGB8 textures — the earlier objective-mandated FRAMEBUFFER_UNSUPPORTED deviation was removed in wave-7 because graded CTS pages assert COMPLETE). Unsized RGBA → COMPLETE; unsized RGB texture → COMPLETE (invalidate-framebuffer.html hard-requires it; unsized RGB renderbuffers cannot exist — renderbufferStorage(RGB) → INVALID_ENUM). Format/attachment-point mismatch → FRAMEBUFFER_INCOMPLETE_ATTACHMENT (CTS hard-asserts).
- **ImageBitmap uploads via hidden native-WebGL readback** (teximage.ts `readImageBitmapPixels`, wave-7): the canvas decode round trip (drawImage→getImageData in present/) destroys the RGB of fully-transparent (α=0) texels and loses the bitmap's storage mode, so image_bitmap_from_* CTS pages (straight `premultiplyAlpha:'none'` sources with an entire α=0 column) cannot pass with pure-JS decoding. The upload path uploads the bitmap into a hidden NATIVE WebGL context (getContext captured at bundle load, before the context-intercept harness patch) and readPixels it back losslessly in the bitmap's OWN storage form (straight for 'none', premultiplied otherwise — per WebGL spec §texImage2D TexImageSource). Singleton context, recursion/context-lost guards, never throws. Fallback: lossy canvas decode + `source.premultiply === false` tag (set by the CTS harness on the bitmap) selects straight — pure-JS canvas APIs fundamentally cannot extract straight α=0 RGB from an ImageBitmap.
- **Depth storage**: Float32Array for ALL DEPTH_COMPONENT_* (mandated by raster contract); depth-stencil surfaces split into `depthData` + `stencilData`.
- **renderbufferStorageMultisample**: `rb._samples` (actual pinned field name), samples > MAX_SAMPLES=4 → INVALID_OPERATION, single-sampled storage (software resolve at blitFramebuffer).
- **TF capture**: draw-time pre-check — if this draw's capture would overflow a bound TF buffer (cumulative session cursor), the draw generates INVALID_OPERATION and captures NOTHING (GLES 3.0 §2.15.2; too-small-buffers.html PASSES). Unbound TF buffers are skipped per-varying; fully-captured primitives count toward `_primitivesWritten`. TF draw-mode mismatch → INVALID_OPERATION. begin requires linked program + non-empty TF varyings + ≥1 buffer (INTERLEAVED) / per-varying (SEPARATE). useProgram/linkProgram reject while TF active; getBufferSubData/bufferData reject TF-bound buffers; bufferData on TF-bound buffer is legal (no INVALID_OPERATION).
- **Sync objects**: event-loop-deferred signaling — `fenceSync` creates the sync with `_signaled = false` and a one-shot `setTimeout(0)` flips it, so `clientWaitSync(..., 0)` returns TIMEOUT_EXPIRED within the same task and ALREADY_SIGNALED after (CTS sync-webgl-specific.html). `clientWaitSync` timeout>0 → INVALID_OPERATION (MAX_CLIENT_WAIT_TIMEOUT_WEBGL=0).
- **Queries**: availability event-loop-deferred — endQuery sets `_resultAvailable` via a batched `setTimeout(0)` flip; ANY_SAMPLES_PASSED(_CONSERVATIVE)/TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN targets; occlusion counts REAL samples via the `sampleCountRef` hook (raster pending — see Known Issues).
- **drawBuffers state is PER-FRAMEBUFFER** (module WeakMap; spec default [COLOR_ATTACHMENT0, NONE×7], synced into `s.drawBuffers` on bind/delete; gated to WebGL2; W1 WEBGL_draw_buffers extension untouched). Documented deviation: default-FB list is [COLOR_ATTACHMENT0] not [BACK] (draw.ts consumers index `db - COLOR_ATTACHMENT0`; getters maps first non-NONE to BACK).
- **`getActiveUniformsiv`**: declared in webgl2.ts per class docs, but WebGL2 IDL names it `getActiveUniforms` — implemented under BOTH names.
- **Limits** (in `defaultLimits()`): MAX_TEXTURE_IMAGE_UNITS=16, MAX_COMBINED=32, MAX_DRAW_BUFFERS=8, MAX_COLOR_ATTACHMENTS=8, MAX_SAMPLES=4, UNIFORM_BUFFER_OFFSET_ALIGNMENT=256, MAX_CLIENT_WAIT_TIMEOUT_WEBGL=0, MAX_TEXTURE_SIZE=8192, MAX_CUBE=8192, MAX_3D=2048, MAX_ARRAY_TEXTURE_LAYERS=2048, MAX_VERTEX_ATTRIBS=16, MAX_VARYING_VECTORS=64, ALIASED_POINT_SIZE_RANGE=[1,1024], ALIASED_LINE_WIDTH_RANGE=[1,1], MAX_TEXTURE_MAX_ANISOTROPY_EXT=16, MAX_COMBINED_*_UNIFORM_COMPONENTS=262144.
- **Extension status** (registry is the source of truth): 'implement' — ANGLE_instanced_arrays, EXT_blend_minmax, EXT_frag_depth, EXT_shader_texture_lod, EXT_sRGB, OES_element_index_uint, OES_fbo_render_mipmap, OES_standard_derivatives, OES_texture_float(+_linear), OES_texture_half_float(+_linear), OES_vertex_array_object, WEBGL_depth_texture, WEBGL_draw_buffers, WEBGL_blend_func_extended, WEBGL_lose_context, WEBGL_debug_renderer_info, WEBGL_debug_shaders, EXT_texture_filter_anisotropic (aliases WEBKIT_/MOZ_), EXT_clip_control, EXT_color_buffer_float, EXT_color_buffer_half_float, EXT_float_blend, EXT_texture_norm16, KHR_parallel_shader_compile, OES_draw_buffers_indexed, WEBGL_clip_cull_distance, WEBGL_multi_draw, WEBGL_multisampled_render_to_texture, WEBGL_render_shared_exponent, WEBGL_compressed_texture_etc/_etc1 (W2, constants-only). 'null' (getExtension → null; legal per CTS): all other compressed formats (s3tc, s3tc_srgb, astc, pvrtc, bptc, rgtc — texImage2D with their internalformats → INVALID_ENUM), EXT_disjoint_timer_query(+webgl2), EXT_depth_clamp, EXT_polygon_offset_clamp, WEBGL_polygon_mode, EXT_texture_mirror_clamp_to_edge, OVR_multiview2, EXT_render_snorm. Core-promoted WebGL1 extensions NOT exposed on WebGL2 (versions:[1]); EXT_disjoint_timer_query NOT advertised on WebGL2 (CTS checks).
- **Drawing-buffer lifecycle**: WeakMap canvas registry; one context per (canvas, type-slot); conflicting getContext → null. `preserveDrawingBuffer:false` is a hint — buffer persists so screenshots see the last frame. Context constructor allocates `_defaultFB` (via raster/formats when available) + `_presentSurface` (present/createCanvasSurface); after each draw/clear touching the default framebuffer, `presentSurface.present()` is called.

## Cross-Agent Contract Notes (IMPORTANT for glsl/raster/present agents)
- **Attrib/instancing convention (draw.ts → glsl)**: the engine fills `ctx.attribs[loc]` with DENSE pools (one pool per bound buffer, laid out consecutively) and `ctx.attribIndices[loc]` = 0-based vertex position for divisor-0 attribs, `floor(instanceId/divisor)` for instanced. glsl codegen MUST read `attribs[loc][attribIndices[loc] * components + c]` — NOT `attribs[loc][vertexId*components+c]`.
- **Occlusion hook (draw.ts → raster)**: draw.ts attaches `(dc as any).sampleCountRef = { value: 0 }` before `rasterizer.draw` and sums `sampleCountRef.value` into the active query's `_result` after. The raster agent MUST increment `sampleCountRef.value` per depth-passed sample when the field is present. DrawCall.textures field EXISTS (per-texture-unit `TextureImage`); `dc.fb` comes from `resolveFramebufferTarget` (real now).
- **Uniform store (gl → glsl)**: `ProgramModel.uniforms[].location` is a FLOAT index into the program's float store. `program._uniformStore = new DataView(floatStore.buffer, floatStore.byteOffset, floatStore.byteLength)` aliases glsl's `floatStore`; float writes: byte = `(location + slotOffset + comp) * 4`; int/uint/bool/sampler writes: index `location + slotOffset + comp` into glsl's `intStore` (uint via `>>>0`, bool 0/1, int `|0`). `elementSlots()` = float stride (scalar/sampler 1, vector 4, matrix cols*4). NOTE: glsl's `Program.uniformMap` values are SEPARATE instances from `uniforms[]` entries — gl resolves locations BY NAME (`pm.uniforms.find(x => x.name === ...)` with `[0]`-normalized fallback); do not reintroduce identity `indexOf` bridging. Matrix addressing is float-index (no `*16`).
- **readPixels row order (gl → raster)**: NO y-flip — raster Surface row 0 = BOTTOM (readPixels(0,0,w,h) returns row 0 first). Default FB: RGBA8/UNSIGNED_BYTE only; W2 same. Pack alignment/skip algorithms implemented in draw.ts.
- **Texture image model (gl → raster)**: `WebGLTexture._image: GLTextureImage` = raster `TextureImage` with `levels[{width,height,depth,data:ArrayBufferView[],stencilData?}]`; cube textures = 6 views per level (+X..-Z order, `faceIndex = face - 0x8515`); 3D/2D_ARRAY levels = one view per layer (`data[z]`, matching the raster sampler's `readTexel`), stencilData flat w×h×d. gl allocates levels via raster formats when available, local format table otherwise. DOM-source uploads (texImage2D/3D, texSubImage2D/3D incl. the explicit-dims 3D overloads) decode to normalized RGBA8 and convert in the source domain (`copyPixelsIntoLevel` DOM branch: `domain = isInteger ? 2 : 0`, ÷255 for float destinations).
- **NEAREST_MIPMAP_LINEAR = 0x2702** (WebGL convention, swapped vs GLES) — raster sampler must interpret filter enums per this convention.
- **TF binding model (gl internal — per updated Khronos spec)**: the indexed bindings (TRANSFORM_FEEDBACK_BUFFER_BINDING[i]) are PER-TF-OBJECT state — `bindBufferBase/Range` must write into the bound `WebGLTransformFeedback._buffers[i]`/`_bufferRanges[i]` and persist there (switching-objects.html PASSES); the generic binding point (`bindBuffer(TRANSFORM_FEEDBACK_BUFFER)`) is GLOBAL context state and `getParameter(TRANSFORM_FEEDBACK_BUFFER_BINDING)` must read that global slot. TRANSFORM_FEEDBACK_ACTIVE/PAUSED getters read the bound TF object; the default TF object lives in a WeakMap and is only exposed in `state.transformFeedback` during an active default-TF session so the draw engine captures into it.
- **Lost/restore lives in `lost.ts`** (cycle-free). Do NOT import lifecycle.ts from extensions/misc.ts (module cycle).
- **Compressed textures**: WEBGL_compressed_texture_etc/_etc1 are 'implement' (constants-only, W2); all other compressed internalformats → INVALID_ENUM (all other compressed extensions 'null') — keep it that way until a compressed format is actually implemented.
