# src/gl/ — WebGL API Surface (WebGL1 + WebGL2 contexts)

## Intent
The complete WebGL 1.0 (`WebGLRenderingContext`) and WebGL 2.0 (`WebGL2RenderingContext`) API surface of the software renderer: all GL state, all WebGL object classes, the error queue, per-call validation, attribute fetch + vertex evaluation, draw-call assembly into the rasterizer, texture/FBO management, readPixels/clear/blit, context lifecycle, and the extension registry. Pure TS, zero runtime deps. Consumes `glsl/` (shader compile/link — contract §1 in `../CONTEXT.md`), `raster/` (DrawCall, formats, sampler, surfaces — contracts §2/§3), `present/` (canvas surfaces, image decode — contract §4). Those modules' `index.ts` files carry the full types; gl/ compiles against them.

**Phase status: Phase 2 COMPLETE.** All `api/` mixins, engine modules (`draw.ts`, `teximage.ts`, `getters.ts`, `lifecycle.ts`, `framebuffer-util.ts`, `lost.ts`), object classes, and all 31 'implement' extension factories are implemented and wired. `installAll` is invoked at the bottoms of `webgl1.ts`/`webgl2.ts`. `npx tsc --noEmit` is clean for src/gl; integration self-test (84 checks) passes against stubbed siblings. Siblings (glsl/, raster/, present/) were still Phase-1 stubs at merge time — gl code keeps try/catch fallbacks for their runtime throws.

## API Surface
- `index.ts` — barrel: exports both context classes, constants (`C1`, `C2`, `CExt`, `C`), all object classes, state model, errors, validation, engine entry points, extension registry + types, `installAll`.
- `webgl1.ts` — `class WebGLRenderingContext` with EVERY WebGL1 method declared (exact spec signatures; arity matters — CTS checks `function.length`). `canvas`/`drawingBufferWidth`/`drawingBufferHeight` are prototype getters. `CONTEXT_TOKEN: unique symbol` gates construction (only `lifecycle.ts` may construct). Bottom: `installConstants(proto, C1)` + `installAll(proto)` + `chainToNative(proto, 'WebGLRenderingContext')`.
- `webgl2.ts` — `class WebGL2RenderingContext extends WebGLRenderingContext` (constructor `super()` + typing depend on the declaration; in NODE the prototype chain also makes `instanceof WebGLRenderingContext` true) with all WebGL2 additions. Bottom: `installConstants(proto, C1)` + `installConstants(proto, C2)` (full constant surface as OWN props — required once the prototype is re-chained), `installAll(proto)` (idempotent; entry.ts also calls), copies the 3 class-body getters from the WebGL1 prototype, then `chainToNative(proto, 'WebGL2RenderingContext')` (REPLACES the class-extends prototype link with the native WebGL2 link in browsers).
- `native-chain.ts` — `chainToNative(ourProto, nativeGlobalName)`: re-chains a class prototype under the native browser class of the same name (browser only; guarded no-op in Node). PROTOTYPE-ONLY — never touches constructor `[[Prototype]]` (that would redirect `super()` to the illegal native constructor). See "Native instanceof chaining" design note below.
- `constants.ts` — `C1` (WebGL1 GLenum values), `C2` (WebGL2 values), `CExt` (extension constants incl. compressed formats, timer query, norm16, clip/cull, draw-buffers), merged `C` for engine use, `installConstants(proto, table)` (enumerable, non-writable). NOTE: C1/C2 are exactly the constants installed on the context prototypes — CTS `constants-and-properties*.html` enumerate `for (var i in gl)` and fail on ANY extra non-function property. Values removed from the WebGL spec or added post-CTS-suite (EXTENSIONS, SHADER_COMPILER, SHADER_BINARY_FORMATS, NUM_SHADER_BINARY_FORMATS, MSAA texture enums, COLOR_ATTACHMENT16-31, STENCIL_INDEX, MAX_VERTEX_ATTRIB_STRIDE/RELATIVE_OFFSET, FRAMEBUFFER_INCOMPLETE_LAYER_TARGETS) live in `CInternal` (merged into `C`, never installed). NOTE: constants.ts follows the Khronos **WebGL** convention where NEAREST_MIPMAP_LINEAR=0x2702 / LINEAR_MIPMAP_NEAREST=0x2701 (swapped vs OpenGL ES) — the raster sampler MUST interpret raw filter values per this same convention.
- `state.ts` — `State` interface + `createDefaultState(version: 1|2)` (+ alias `createState`) with spec defaults; `Limits`/`defaultLimits()`; per-attrib/VAO/Blend/Stencil/PixelStore state. Plain mutable data, no logic.
- `errors.ts` — `ErrorQueue` (push/get/peek/hasErrors/clear; cap 256, spec ordering).
- `validation.ts` — `validateObject` (TypeError for non-WebGLObject; INVALID_OPERATION + null for cross-context/deleted), numeric/enum/string guards.
- `objects/` — one file per class: WebGLObject (abstract base: `_context` tag, `_deleted`), WebGLBuffer (`_target`, `_data`, `_size`, `_usage`, `_deletePending`, `_tfRangeBindings`), WebGLTexture (`_levels[faceIndex][level]`, `_params` — spec defaults incl. MIN_FILTER=NEAREST_MIPMAP_LINEAR(0x2702), MAX_LEVEL=1000, MIN/MAX_LOD=∓1000, MAX_ANISO=1; `_image: GLTextureImage|null`, `_deletePending`), WebGLShader (+`_translatedSource`: set on successful compile, '' on failure, null on shaderSource reset), WebGLProgram (+`_uniformStore: DataView|null`, `_blockStores`, `_bindAttribLocations`, `_transformFeedbackVaryings`, `_tfBufferMode`, `_linkComplete`), WebGLFramebuffer (`_attachments: Map<GLenum, FramebufferAttachment>`, `_status`, `_multisampled`), WebGLRenderbuffer (`_surface: Surface|null`, `_samples`), WebGLVertexArrayObject (holds VAOState), WebGLSampler, WebGLQuery (`_active`, `_result`, `_resultAvailable`), WebGLSync (immediate-signaled), WebGLTransformFeedback, `aux.ts` (WebGLUniformLocation {_program,_index,_name}, WebGLActiveInfo, WebGLShaderPrecisionFormat), `index.ts` (barrel + `OBJECT_CLASSES` + `Resources` + `createObject` + bottom-of-module `chainToNative` calls for ALL 14 concrete classes).
- `framebuffer-util.ts` — `resolveFramebufferTarget(ctx)` (real: builds the `FramebufferTarget` the rasterizer draws into) + `checkFramebufferStatus` full completeness rules (attachment completeness, format/attachment-point match, color-buffer format match, W2 RGB8→FRAMEBUFFER_UNSUPPORTED, draw-buffer count, mip level, multisample mismatch, layer).
- `lost.ts` — shared context-lost/restore engine (cycle-free: imports only state/errors/constants/present/raster types). `lifecycle.ts` re-exports; `extensions/misc.ts` WEBGL_lose_context delegates. Events dispatched async; preventDefault on the lost event gates restore.
- `extensions/` — `index.ts`: `EXTENSION_SPECS` registry (canonical name, aliases, `versions: 1|2[]`, status 'implement'|'null'), `getSupportedExtensionNames(version)`, `getExtensionObject(ctx, name)` (alias-aware, version-checked, singleton cache on `ctx._extensions`); `types.ts`: full interfaces for every extension. All 31 'implement' factories live in `extensions/<group>.ts` (buffers.ts, misc.ts, draw-buffers.ts, clip-state.ts, ...). `getSupportedExtensions()` lists IFF `getExtension()` returns an object (hard CTS invariant — get-extension.html). 'null' specs return null from getExtension and are NOT listed.
- Engine modules: `draw.ts` (`executeDraw`/`executeClear`/`executeReadPixels`/`executeBlitFramebuffer`/`executeClearBuffer`/`executeMultiDrawArrays`/`executeMultiDrawElements` + `DrawRequest` — contract §2 pipeline: attr fetch → per-vertex `vertex.run` → packed records → TF capture → occlusion hook → `rasterizer.draw`), `teximage.ts` (upload/copy/compressed/mipmap/storage with full overload dispatch + pixelStore semantics; local format table fallback when raster/formats stubbed; generateMipmap with filter-based box sampling), `getters.ts` (full getParameter table incl. VERSION/VENDOR/RENDERER/SHADING_LANGUAGE_VERSION strings — CTS functions-returning-strings.html; getParameter(EXTENSIONS) is INVALID_ENUM per spec), `lifecycle.ts` (`createContext` WeakMap registry: one context per canvas per type-slot; 'webgl'+'experimental-webgl' share slot; webgl2 conflicts → null; resize/lose/restore; getContextAttributes resolution; `hideInternalFields` re-defines the context's own `_`-prefixed fields as NON-ENUMERABLE after construction — CTS `constants-and-properties*.html` enumerate `for (var i in gl)` and fail on any extra non-function property).
- `api/` — prototype-mixin modules (`context.ts`, `state.ts`, `buffers.ts`, `vertex-attrib.ts`, `textures.ts`, `teximage.ts`, `programs.ts`, `uniforms.ts`, `framebuffers.ts`, `draw.ts`, `webgl2.ts`); each exports `installXxx(proto)` (assignment preserves arity); `index.ts` `installAll(proto)` aggregates.

## Constraints
- Each file ≤ ~1000 lines (mixin pattern exists precisely for this; do NOT grow webgl1.ts/webgl2.ts class bodies beyond signatures — implementations live in api/ modules).
- Zero runtime deps; no DOM in core paths (canvas is abstract via present/).
- GL error semantics: WebIDL conversion failures THROW TypeError (JS conversion per WebGL spec); cross-context/deleted objects → INVALID_OPERATION + no-op; internal exceptions NEVER escape — catch at the API boundary, report via GL errors. Error queue ordering per spec (oldest first, FIFO).
- No per-fragment allocation in hot paths (draw pipeline uses preallocated typed-array scratch).
- Correct method arity (function.length) and prototype placement: constants + getters on prototype, non-writable.
- All validation must match the WebGL spec: value ranges, buffer offsets/alignment (UNPACK_ALIGNMENT, uniform buffer offset alignment 256), FBO completeness before draw (INVALID_FRAMEBUFFER_OPERATION), program link state, uniform type/size mismatch → INVALID_OPERATION, MAX_* limits consistent with `Limits`/`defaultLimits()`.
- Contract §1 conformance: `compileShader`/`linkProgram` from glsl/; ProgramModel.uniforms[].location is the index into the per-program `_uniformStore` DataView (uniform* calls write there); sampler values validated < MAX_COMBINED_TEXTURE_IMAGE_UNITS; matrix transpose must be false (INVALID_VALUE).
- Contract §2 conformance: vertex records packed `[px,py,pz,pw, pointSize, varyings...]` per Program.varyings (`RECORD_HEADER_FLOATS = 5`); DrawCall carries the full state snapshot.

## Design Decisions (CTS-backed where noted)
- **Class hierarchy**: `WebGL2RenderingContext extends WebGLRenderingContext` (constructor `super()` + typing; in NODE the prototype chain also makes `instanceof WebGLRenderingContext` true for WebGL2 contexts). In BROWSERS the prototypes are re-chained under the native classes (see "Native instanceof chaining"); WebGL1 class carries all base methods; WebGL2 adds on top. Interface merging adds typed getExtension overloads.
- **Native instanceof chaining**: the CTS harness checks `ctx instanceof WebGLRenderingContext`/`WebGL2RenderingContext` (and object identity via instanceof) against the NATIVE browser classes (`webgl-test-utils.js` `isWebGLContext`) — a failed check falls back to `gl.getImageData(...)` and breaks rendering tests. `native-chain.ts` `chainToNative` re-chains each of our class prototypes UNDER the native prototype of the same name (browser only; guarded no-op in Node). Mapping: the 2 context classes (webgl1.ts/webgl2.ts bottoms) + all 14 concrete object classes (objects/index.ts bottom: WebGLBuffer, WebGLTexture, WebGLProgram, WebGLShader, WebGLFramebuffer, WebGLRenderbuffer, WebGLVertexArrayObject, WebGLSampler, WebGLQuery, WebGLSync, WebGLTransformFeedback, WebGLUniformLocation, WebGLActiveInfo, WebGLShaderPrecisionFormat). The abstract `WebGLObject` base is NOT chained (only instance fields, no runtime instanceof checks against it). PROTOTYPE-ONLY: constructor `[[Prototype]]`s are untouched (native WebGL constructors are illegal — redirecting `super()` would throw "Illegal constructor"). Consequences in browsers: (a) WebGL2 instances are NO LONGER `instanceof WebGLRenderingContext` — mirrors native Chromium (separate interfaces); (b) instances keep `instanceof OurConcreteClass` (their immediate prototype is still our prototype), so all internal instanceof checks stay valid — verified by audit: no runtime checks against `WebGLObject` or `WebGLRenderingContext` exist; (c) the WebGL2 prototype must own everything it previously inherited through the class-extends chain — hence C1 constants and the `canvas`/`drawingBufferWidth`/`drawingBufferHeight` getters are installed as OWN properties on `WebGL2RenderingContext.prototype` in webgl2.ts.
- **Prototype-mixin implementation**: class declarations own signatures + arity; `api/<group>.ts` replaces stub bodies via assignment.
- **Error/validation model**: TypeError for WebIDL conversion failures; INVALID_* via ErrorQueue; internal exceptions swallowed at API boundary.
- **antialias reporting**: W1 reports `false` (CTS `context/context-attributes-alpha-depth-stencil-antialias.html` requires real AA pixels for true); W2 reports exactly what was requested (CTS `conformance2/context/context-attributes-depth-stencil-antialias-obeyed.html`). Buffer is single-sampled in both cases.
- **failIfMajorPerformanceCaveat**: always create the context and report the requested value — no CTS test exercises it (checked `context/context-attributes.html`); software implementations may return null per spec but creating is safer.
- **Resize semantics** (verified against CTS `canvas/canvas-test.html`, `canvas/viewport-unchanged-upon-resize.html`, `canvas/zero-sized-canvas.html`, `canvas/drawingbuffer-test.html`): realloc + clear (color 0, depth 1.0, stencil 0), viewport/scissor/state preserved, zero-size → 1×1, `drawingBufferWidth/Height` live getters.
- **Context loss** (CTS `context/context-lost.html` PASSES; `context-lost-restored.html` passes except the raster texture-draw bug below): events dispatched async; `preventDefault()` on the lost event gates restore; resize while lost reallocates nothing but stays lost. While lost: getters (getParameter/getContextAttributes/getString/getSupportedExtensions/getExtension) return null; ALL void calls are SILENT no-ops (no error — the api/ guards push nothing; the single CONTEXT_LOST_WEBGL comes from getError); `loseContext()` on an already-lost context → INVALID_OPERATION and `restoreContext()` on a live context → INVALID_OPERATION (pushed to the queue, observable via getError); create* (incl. extension creates like OES createVertexArrayOES) return NON-NULL objects with NO error — `[WebGLHandlesContextLoss]` is NOT on creates (CTS nonNullTests), but is* on such objects returns false. `getError()` while lost: FIRST call per loss epoch returns CONTEXT_LOST_WEBGL, subsequent calls drain the queue normally (`getErrorWhileLost`/`resetLostErrorState` in lost.ts; reset per loseContext + doRestore). The extension singleton cache is untouched by the lost path; `doRestore` re-creates non-WEBGL_lose_context singletons (context-lost-restored.html requires NEW objects without prior properties) while WEBGL_lose_context keeps identity.
- **RGB8 color attachment on WebGL2** → FRAMEBUFFER_UNSUPPORTED (objective-mandated; CTS tolerant). Format/attachment-point mismatch → FRAMEBUFFER_INCOMPLETE_ATTACHMENT (CTS hard-asserts).
- **Depth storage**: Float32Array for ALL DEPTH_COMPONENT_* (mandated by raster contract); depth-stencil surfaces split into `depthData` + `stencilData`.
- **renderbufferStorageMultisample**: `rb._samples` (actual pinned field name), samples > MAX_SAMPLES=4 → INVALID_OPERATION, single-sampled storage (software resolve at blitFramebuffer).
- **TF overflow**: clamp + stop capture, no GL error. TF draw-mode mismatch → INVALID_OPERATION. begin requires linked program + non-empty TF varyings + ≥1 buffer (INTERLEAVED) / per-varying (SEPARATE).
- **Sync objects**: event-loop-deferred signaling — `fenceSync` creates the sync with `_signaled = false` and a one-shot `setTimeout(0)` flips it (objects/webgl-sync.ts; api/webgl2.ts L602-606), so `clientWaitSync(..., 0)` returns TIMEOUT_EXPIRED within the same task and ALREADY_SIGNALED after (CTS sync-webgl-specific.html). `clientWaitSync` timeout>0 → INVALID_OPERATION (MAX_CLIENT_WAIT_TIMEOUT_WEBGL=0).
- **Queries**: availability event-loop-deferred — endQuery sets `_resultAvailable` via a batched `setTimeout(0)` flip (api/webgl2.ts L203-235); `ANY_SAMPLES_PASSED`/`ANY_SAMPLES_PASSED_CONSERVATIVE`/`TRANSFORM_FEEDBACK_PRIMITIVES_WRITTEN` targets; occlusion counts REAL samples via the `sampleCountRef` hook (below — raster pending).
- **`getActiveUniformsiv`**: declared in webgl2.ts per class docs, but WebGL2 IDL names it `getActiveUniforms` — implemented under BOTH names.
- **Limits** (in `defaultLimits()`): MAX_TEXTURE_IMAGE_UNITS=16, MAX_COMBINED=32, MAX_DRAW_BUFFERS=8, MAX_COLOR_ATTACHMENTS=8, MAX_SAMPLES=4, UNIFORM_BUFFER_OFFSET_ALIGNMENT=256, MAX_CLIENT_WAIT_TIMEOUT_WEBGL=0, MAX_TEXTURE_SIZE=8192, MAX_CUBE=8192, MAX_3D=2048, MAX_ARRAY_TEXTURE_LAYERS=2048, MAX_VERTEX_ATTRIBS=16, MAX_VARYING_VECTORS=64, ALIASED_POINT_SIZE_RANGE=[1,1024], ALIASED_LINE_WIDTH_RANGE=[1,1], MAX_TEXTURE_MAX_ANISOTROPY_EXT=16, MAX_COMBINED_*_UNIFORM_COMPONENTS=262144.
- **Extension status** (registry is the source of truth): 'implement' — ANGLE_instanced_arrays, EXT_blend_minmax, EXT_frag_depth, EXT_shader_texture_lod, EXT_sRGB, OES_element_index_uint, OES_fbo_render_mipmap, OES_standard_derivatives, OES_texture_float(+_linear), OES_texture_half_float(+_linear), OES_vertex_array_object, WEBGL_depth_texture, WEBGL_draw_buffers, WEBGL_blend_func_extended, WEBGL_lose_context, WEBGL_debug_renderer_info, WEBGL_debug_shaders, EXT_texture_filter_anisotropic (aliases WEBKIT_/MOZ_), EXT_clip_control, EXT_color_buffer_float, EXT_color_buffer_half_float, EXT_float_blend, EXT_texture_norm16, KHR_parallel_shader_compile, OES_draw_buffers_indexed, WEBGL_clip_cull_distance, WEBGL_multi_draw, WEBGL_multisampled_render_to_texture, WEBGL_render_shared_exponent. 'null' (getExtension → null; legal per CTS): all compressed formats (s3tc, s3tc_srgb, astc, etc, etc1, pvrtc, bptc, rgtc — texImage2D with their internalformats → INVALID_ENUM), EXT_disjoint_timer_query(+webgl2), EXT_depth_clamp, EXT_polygon_offset_clamp, WEBGL_polygon_mode, EXT_texture_mirror_clamp_to_edge, OVR_multiview2. Core-promoted WebGL1 extensions NOT exposed on WebGL2 (versions:[1]); EXT_disjoint_timer_query NOT advertised on WebGL2 (CTS checks).
- **Drawing-buffer lifecycle**: WeakMap canvas registry; one context per (canvas, type-slot); conflicting getContext → null. `preserveDrawingBuffer:false` is a hint — buffer persists so screenshots see the last frame. Context constructor allocates `_defaultFB` (via raster/formats when available) + `_presentSurface` (present/createCanvasSurface); after each draw/clear touching the default framebuffer, `presentSurface.present()` is called.

## Cross-Agent Contract Notes (IMPORTANT for glsl/raster/present agents)
- **Attrib/instancing convention (draw.ts → glsl)**: the engine fills `ctx.attribs[loc]` with DENSE pools (one pool per bound buffer, laid out consecutively) and `ctx.attribIndices[loc]` = 0-based vertex position for divisor-0 attribs, `floor(instanceId/divisor)` for instanced. glsl codegen MUST read `attribs[loc][attribIndices[loc] * components + c]` — NOT `attribs[loc][vertexId*components+c]`.
- **Occlusion hook (draw.ts → raster)**: the committed raster `DrawCall` has NO sampleCount field — draw.ts attaches `(dc as any).sampleCountRef = { value: 0 }` before `rasterizer.draw` and sums `sampleCountRef.value` into the active query's `_result` after. The raster agent MUST increment `sampleCountRef.value` per depth-passed sample when the field is present. DrawCall.textures field EXISTS (per-texture-unit `TextureImage`); `dc.fb` comes from `resolveFramebufferTarget` (real now).
- **Uniform store (gl → glsl)**: `ProgramModel.uniforms[].location` is a FLOAT index into the program's float store (verified against glsl linker `emitType`/`elemFloatStride` + codegen `uniformRead`). `program._uniformStore = new DataView(floatStore.buffer, floatStore.byteOffset, floatStore.byteLength)` aliases glsl's `floatStore`; float writes: byte = `(location + slotOffset + comp) * 4`; int/uint/bool/sampler writes: index `location + slotOffset + comp` into glsl's `intStore` (uint via `>>>0`, bool 0/1, int `|0`). `elementSlots()` = float stride (scalar/sampler 1, vector 4, matrix cols*4). NOTE: glsl's `Program.uniformMap` values are SEPARATE instances from `uniforms[]` entries — gl resolves locations BY NAME (`pm.uniforms.find(x => x.name === ...)` with `[0]`-normalized fallback); do not reintroduce identity `indexOf` bridging. Matrix addressing is float-index (no `*16`).
- **readPixels row order (gl → raster)**: NO y-flip — raster Surface row 0 = BOTTOM (readPixels(0,0,w,h) returns row 0 first). Default FB: RGBA8/UNSIGNED_BYTE only; W2 same. Pack alignment/skip algorithms implemented in draw.ts.
- **Texture image model (gl → raster)**: `WebGLTexture._image: GLTextureImage` = raster `TextureImage` with `levels[{width,height,depth,data:ArrayBufferView[],stencilData?}]`; cube textures = 6 views per level (+X..-Z order, `faceIndex = face - 0x8515`). gl allocates levels via raster formats when available, local format table otherwise.
- **NEAREST_MIPMAP_LINEAR = 0x2702** (WebGL convention, swapped vs GLES) — raster sampler must interpret filter enums per this convention.
- **TF binding model (gl internal — per updated Khronos spec)**: the indexed bindings (TRANSFORM_FEEDBACK_BUFFER_BINDING[i]) are PER-TF-OBJECT state — `bindBufferBase/Range` must write into the BOUND `WebGLTransformFeedback._buffers[i]`/`_bufferRanges[i]` and persist there (switching-objects.html); the generic binding point (`bindBuffer(TRANSFORM_FEEDBACK_BUFFER)`) is GLOBAL context state and `getParameter(TRANSFORM_FEEDBACK_BUFFER_BINDING)` must read that global slot. CAVEAT: the current implementation (api/webgl2.ts `syncTfBuffers` L348-359) instead rebuilds `tf._buffers` from a global mirror (`tfBindingAtIndex` L328-340 scans `buffer._tfRangeBindings`) at every bind/begin — this CORRUPTS per-object bindings (last-created wins) and is the root bug of switching-objects.html (43P/6F); fix in api/webgl2.ts + getters.ts (see cluster map). `TRANSFORM_FEEDBACK_ACTIVE/PAUSED` getters read the bound TF object; the default TF object lives in a WeakMap (api/webgl2.ts) and is only exposed in `state.transformFeedback` during an active default-TF session so the draw engine captures into it.
- **Lost/restore lives in `lost.ts`** (cycle-free). Do NOT import lifecycle.ts from extensions/misc.ts (module cycle).
- **Compressed textures**: all compressed internalformats → INVALID_ENUM (all 'null' extensions) — keep it that way until a compressed format is implemented.
